术语表 ​

术语含义
项目（Project）一组共同分析、授权和查询的仓库，是 Ershu 的主要访问边界。
仓库（Repository）项目中的一个 GitHub、GitLab 或受信任本地代码源，记录目标分支、凭据和更新策略。
全项目分析（full_project）覆盖项目所有有效仓库的分析。第一次成功结果会建立后续增量分析所需的基线。
增量分析在已有全项目基线上处理新提交，并更新项目级结果的分析。
运行（Run）一次分析请求及其完整状态，包括范围、阶段、事件、检查点、用量和结果。
队列项（Queue item）Worker 可以领取和续租的持久任务记录。API 创建运行不等于任务已经执行。
分析快照API 保存的当前运行视图。刷新或实时连接中断后，前端可以重新读取它。
仓库事实从目标提交确定性提取的树、文件、语言和结构信息，不等同于模型生成的解释。
代码索引用于列出和定位代码实体、符号与来源位置的结构化结果。
知识关系文件、符号和其他代码实体之间的关系，用于关系图和上下文查询。
词法搜索按名称和文本匹配已经建立的索引，不依赖向量相似度。
语义搜索用嵌入向量按含义查找内容，需要 Milvus 和嵌入设置。
混合搜索组合词法与语义结果；支持的语义失败可以被明确报告为词法回退。
模型通道管理员保存并启用的一组模型提供方、模型和凭据设置，供文档生成与问答使用。
MCP模型上下文协议。Ershu 通过它为开发智能体提供项目范围的只读查询工具。
MCP 密钥带项目范围的 Bearer 凭据。服务端保存的是带版本的 HMAC-SHA256 摘要，不是明文密钥。
OPAQUE网页密码注册与登录使用的协议。服务端保存 OPAQUE password file，而不是可直接还原的密码。
运行时设置可以由管理员在线修改，并保存到数据库的配置。其数据库值可覆盖同名启动值。
启动设置进程从环境读取的配置。部分值用于提供运行时设置默认值，安全与连接类设置通常只在启动时生效。
Core安装进 API、Worker 与 MCP 的共享 Python 包，负责共同数据和规则；不是独立网络服务。
来源引用文档、搜索或问答结果指向仓库、提交、路径和位置的信息，用于回到当前源码核对。

术语随数据模型与公开契约更新。需要精确字段时，应继续查看对应配置或开发页面，而不是从本表推断未说明行为。

事实来源：Core 数据模型、API 结构、Worker 输出、搜索契约、MCP 认证和前端显示逻辑。
