阅读文档、搜索项目和继续提问 ​

一次分析完成后，你可以从三个入口理解项目：Docs 适合顺序阅读，Search 适合定位具体内容，Docs 中的问答适合把多个结果整理成带引用的回答。它们共享项目权限，但不是同一种查询方式。

开始前确认产物存在 ​

进入项目的 运行 页面，打开最近一次完整项目运行。状态应为 completed 或 completed_with_warnings，详情页应列出实际生成的文档。

如果运行失败、被取消，或没有生成任何文档，先处理运行警告和 Worker 错误。空的 Docs 页面不能通过重新加载浏览器变出内容。

阅读生成文档 ​

  1. 打开项目的 Docs 页面。
  2. 从左侧列表选择一篇文档。文档按仓库和类别分组；项目包含多个仓库时，先确认选中了正确仓库。
  3. 使用文档内标题或右侧页内目录移动到需要的章节。
  4. 遇到源码引用时选择引用，打开来源预览。

成功后，主区域会显示完整文档，当前章节会随阅读位置变化；选择有效引用后，会出现对应的仓库、路径、行号和源码片段。引用的作用是让你回到证据，不代表生成文字可以脱离源码单独作为事实。

文档中的内部链接会在 Ershu 文档间跳转。外部链接会先要求确认。Mermaid 图可以单独放大查看。

搜索项目 ​

打开项目的 Search 页面，输入查询内容，再选择一种方式：

  • 关键词：按输入词查找内容，适合函数名、配置名和错误文字；
  • 语义：按含义查找，需要可用的向量模型（embedding）通道和语义索引；
  • 混合：组合语义和关键词结果；语义能力不可用时，可以明确降级到关键词。

当前页面只提供一个可选的仓库筛选。你可以搜索全部仓库，也可以选择其中一个仓库。页面目前没有分支、语言、路径或内容类型筛选，不要按这些旧用法寻找控件。

选择搜索按钮后，成功结果会显示：

  • 返回数量；
  • 内容片段；
  • 代码、文档、API、README 或配置等结果类型；
  • 来源路径和可用的行号；
  • 展开后可见的语言、文档或章节信息。

点击结果卡片可以展开完整片段。当前结果卡片不会自动跳到 Docs，也不会直接把结果带入问答。

理解搜索降级 ​

  • 语义方式不可用时，不应悄悄伪装成关键词搜索。请检查 embedding 通道和本次运行的搜索索引状态。
  • 混合方式可以回退到关键词。页面会显示降级提示，说明当前结果没有完整使用语义能力。
  • 关键词方式没有结果时，先换成源码中更独特的符号、配置名或错误文字，再检查仓库筛选是否选错。

在 Docs 中发起项目问答 ​

问答入口位于 Docs 页面。打开问答面板并输入一个能被源码或文档验证的问题，例如：“这个项目如何加载配置？”

当前问答范围始终是整个项目：

  • 它不是只针对正在阅读的文档；
  • 它也不是只针对当前章节；
  • 项目包含多个仓库时，回答可能引用不同仓库的内容。

发送后，面板会显示用户消息，并通过流式响应逐步补充回答。成功的回答会包含正文和可用引用；选择引用后，可像文档引用一样打开来源预览。

你还可以：

  • 新建会话；
  • 打开已有会话；
  • 按标题搜索会话；
  • 删除不再需要的会话。

如果回答显示仅检索结果或没有上下文，先确认项目确实有可检索内容，再检查可用模型通道。不要把没有引用、无法回到项目证据的回答当成已经核实的结论。

选择合适的入口 ​

你的问题先用哪个入口成功判据
我想系统了解项目Docs找到结构化文档，并能从引用回到源码
我知道一个函数名或错误文字关键词搜索结果显示相关路径和内容片段
我只知道概念，不知道源码用词语义或混合搜索结果相关，且页面没有未处理的降级提示
我需要综合多个来源Docs 中的项目问答回答包含可以打开的项目引用

三种入口都没有结果时，回到运行详情检查生成文档、搜索索引和警告，而不是重复提交相同查询。
